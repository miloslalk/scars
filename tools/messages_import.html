Messages Admin

Import messages from an XLSX spreadsheet and save to Firebase RTDB at messages/{id}. Column A = skip marker ("x" to skip), Column C = other language, Column D = English.

1) Login

Use Google sign-in (same account you use in the app).

2) Import from Spreadsheet

Select the .xlsx file. Rows with "x" in column A are skipped. Column C = other language, Column D = English.

3) Review & Save

Review messages, then click Save All to write to Firebase.
